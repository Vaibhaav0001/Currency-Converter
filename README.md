💱 Currency Converter
A simple and functional Currency Converter application built using HTML, CSS, and JavaScript. This tool allows users to convert between different currencies in real-time with a user-friendly interface. The exchange rates are fetched from a live API.

✨ Features
🔄 Convert between multiple currencies

⌨️ Easy-to-use input fields and dropdowns

🎯 Accurate conversion logic

💻 Clean and responsive UI

🚀 Fast and lightweight

🛠️ Technologies Used
HTML – For structuring the app

CSS – For styling and layout

JavaScript – For implementing conversion logic and handling DOM updates

🚀 How It Works
Select the base currency and the target currency from the dropdowns.

Enter the amount you want to convert.

The converted amount is shown instantly based on the exchange rate.

Swap currencies to reverse the conversion.

📂 Setup Instructions
Clone this repository:https://github.com/Vaibhaav0001/Currency-Converter
Open the index.html file in your browser.
